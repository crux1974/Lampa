# Alcopac UA — застосунок для LG webOS


Готовий пакет: `webos/Alcopac_UA_1.0.8.ipk`. Застосунок «Alcopac UA» (іконка — золотий тризуб) завантажує Lampa з вашого сервера всередину себе, без заставки. Тому:

- налаштування, плагіни й вхід у CUB зберігаються після виходу;
- Lampa розпізнає телевізор LG так само, як в офіційному застосунку («Назад», вихід, програвач LG);
- працюють http-плагіни.

**Зміна адреси сервера**: утримайте ◀ (вліво) секунду або виберіть «Адреса сервера» в головному меню чи налаштуваннях Lampa. У списку адрес: OK — відкрити, ◀ ▶ — змінити (✎) або видалити (✕), «+ Додати адресу» — нова, «🔍 Перевірка пульта» — коди кнопок (OK — закрити).

Сервер, який не вдається вбудувати, відкривається напряму; тоді на старті півтори секунди видно підказку «Натисніть ◀ — змінити сервер».

Встановлення — через режим розробника LG (Developer Mode) і webOS Dev Manager. Перезібрати пакет після змін у `webos/app/`: `python3 build.py` у папці `webos/`.
