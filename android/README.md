# Alcopac UA для Android (телефон і Android TV)

Lampa з вашого сервера у повноекранному WebView.

- Встановлення: `Alcopac_UA_1.1.0.apk` (дозволити встановлення з невідомих джерел).
- Адреса за замовчуванням: `http://92-5-178-165.sslip.io` (працює будь-де — для друзів).
- Вдома (щоб працював TorrServer на роутері): «Вибрати…» → «Вдома через роутер» (`http://192.168.8.1:8095`).
- Зміна адреси: **довге «Назад»** або кнопка **«Меню»** на пульті; також вікно відкривається саме, якщо сервер не відповідає.
- Коротке «Назад» передається в Lampa (закриває меню й екрани).
- Працюють http-плагіни, повноекранне відео, Android TV (є банер для лаунчера).
